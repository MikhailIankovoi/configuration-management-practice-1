# Практическая работа №1 по конфигурационному управлению

Эмулятор командной оболочки, разработанный в рамках дисциплины
«Конфигурационное управление».

## Вариант

Вариант №29.

## Язык программирования

Python 3.

## Описание проекта

Программа представляет собой эмулятор командной оболочки UNIX-подобной
операционной системы.

Эмулятор работает с виртуальной файловой системой (VFS), загружаемой
из директории на диске. Все операции с виртуальной файловой системой
выполняются в оперативной памяти.

## Параметры запуска

Эмулятор поддерживает следующие параметры командной строки:

- `--vfs` — путь к физическому расположению виртуальной файловой системы;
- `--script` — путь к стартовому скрипту.

Пример запуска с указанием VFS:

`python -m src.main --vfs vfs_samples`

## Структура проекта

- `src` — исходный код программы;
- `tests` — автоматические тесты;
- `scripts` — стартовые скрипты и скрипты операционной системы;
- `vfs_samples` — примеры виртуальных файловых систем;
- `run.bat` — скрипт запуска программы;
- `.gitignore` — список файлов и директорий, исключённых из Git.

## Реализуемые команды

В рамках работы будут реализованы следующие команды:

- `ls` — просмотр содержимого текущей директории;
- `cd` — переход между директориями;
- `pwd` — вывод текущего пути;
- `cal` — вывод календаря;
- `chmod` — изменение прав доступа;
- `vfs-load` — загрузка новой виртуальной файловой системы;
- `exit` — завершение работы эмулятора.

## Запуск программы

`run.bat`
